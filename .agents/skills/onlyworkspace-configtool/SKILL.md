# ConfigTool workflow

- A211: new profiles offer six presets (ollama, gemini, anthropic, openai, qwen, openai-compatible). ProviderCompatibility normalizes retired compatible types in memory before validation; loading never persists the conversion. Save/import/staged apply/restore share the conversion. Preserve endpoint/model/auth/secret references and the external classification of retired cloud presets; invalidate their capability cache and prior grants/history. Azure, Perplexity and Ollama Cloud retain their original protocol only for existing profiles; the editor adds that profile's legacy item temporarily. Generic connections need an explicit URL and support none/bearer, without proprietary capability readers or provider web search.

- A205: no card-generation controls, quotas, resets or cloud mailbox consents. Mailbox rows contain archive selection only; retain closed-store removal and PST own-address edits. Exposure offers Solo locale/Minimo/Standard/Esteso (Extended=4, display3); legacy Full/3 reads as Standard without rewriting files. Notice v4 and old host-only consents require explicit per-profile renewal. The notice text/declarations remain unchanged pending A225.

- `ArchiveSearchForm` exposes local amount/currency/deadline filters via `ArchiveQuery.FactFilters`, independent of received dates. The query text also accepts explicit reference filters through `ArchiveSearchText`. Flow preview shows logical Message-ID rows, reasons/source phrases and physical folder locations; its context menu reads the acquired text of each copy, without requesting a provider. Keep the source preview and incomplete fact recovery visible. Constrain the root column and wrap filters to the viewport; the minimum-size search page scrolls while preserving results/preview height. Minimum bounds follow `Ui.Px` after DPI/font changes. A net48 UI host must carry the built exe config (including net48 startup) and manifest; copying only the source App.config can leave it DPI-unaware. Distinguish native 100/150% monitor results from simulated 125% layouts.

- User preferences use a path-derived cross-process mutex around read/change/atomic replace, including session reset. Missing flags are false; unreadable/corrupt content and invalid flag values throw. Archive collection fails closed; MailboxAuthorizationPanel shows an indeterminate choice and failed saves until reread. Do not replace a corrupt preferences file with defaults. FileConfigurationServiceTests includes independent-process writers on both targets.

- Read `src/OnlyWorkspace.ConfigTool/Program.cs` for CLI parsing, `src/OnlyWorkspace.ConfigTool/Forms/` and `src/OnlyWorkspace.ConfigTool/Tray/` for UI, and `docs/admin/configtool.md` for the user workflow. Wizard and mailbox loading live in `SetupWizardForm.cs` and `MailboxAuthorizationPanel.cs` under Forms.
- CLI syntax is in `Program.PrintUsage`: `validate <file.json>`, `show [config_path]`, `test [config_path]`, `import <source.json> [target_dir] [--skip-test]`, `backup [dest.owbak] [config_dir]`, `restore <source.owbak> [config_dir]`. Resolve the shipped runtime with `. ./scripts/build-paths.ps1; $cli = (Get-OnlyWorkspaceBuildPaths -RepositoryRoot $PWD.Path -Project OnlyWorkspace.ConfigTool).TargetPath`, then use `& $cli validate ./deployment/config.template.json | Out-Host` for a read-only check. ConfigTool is WinExe: use a pipeline or `Start-Process -Wait -PassThru -WindowStyle Hidden` when collecting its exit code, so a previous native command's LASTEXITCODE is not mistaken for its result.
- `validate` reads the exact filename; `show` and `test` resolve its containing directory and load that directory's `config.json`. Omitted paths target the real configuration. `test` and default `import` contact providers; use explicit isolated directories and `--skip-test` for offline import trials. Internal `apply-staged`, `restore-authorized` and `admin-password-apply` commands are GUI/UAC handoffs, not substitutes for public CLI flows.
- `ConfigurationBackupService` in `src/OnlyWorkspace.Infrastructure/Configuration/` backs up config and the DPAPI LocalMachine vault, not archive or per-user data. Verify same-machine vault readability for restore; distinguish this backup from a full installation rollback. Storage locations are in `docs/admin/configurazione.md` and `docs/admin/sicurezza.md`.
- Vault absence revokes in-memory keys; a read/decryption failure preserves the old copy while failing the load. Check missing, zero-byte, malformed and valid encrypted-empty vaults separately, rather than assuming every present file is valid. Pane/indexer must reject clients/results captured before removal or rotation, independently of profile-policy changes; cover repeated reload and restoration.
- DiagnosticsExporter exports system metadata and storage measurements only: never include config, logs, email text, databases, history files or keys. A diagnostics ZIP is not a backup.
- Use `LlmProfileConfig.IsExternal` for the effective destination and attachment controls. Cloud providers and non-loopback endpoints force the displayed indicator; the editable `External` flag only makes policy stricter and must not be overwritten by that computed display state. Loopback becomes local again when no explicit external flag is set.
- GUI saves, direct/elevated, restore and CLI import use the pair replacement in `ConfigurationBackupService`. Import validates structure/config and performs any health checks before persistence; profiles/auth/secret use ordinal case-insensitive matching and reject duplicate recognized names. A nonempty inline secret sets the generated profile key; absent/null/empty input preserves SecretRef. Test actual net48/net10 CLI second-write failures with and without an old vault, plus shared recovery failure retaining a readable backup. A retained backup is named without key values; handled rollback does not establish crash/power-loss atomicity.
- Keep GUI/tray single-instance signaling and elevated writers intact. For DPI changes use `Ui.ScaleFromDesignDpi` and `Ui.SetFont` in `src/OnlyWorkspace.ConfigTool/Forms/ThemedControls.cs`; test with a host carrying the app manifest/config, since a PowerShell WinForms host does not reproduce net48 DPI startup.
- Interactive controls need a plain Italian tooltip explaining effect and Save/UAC requirements (`ConfigToolTooltipTests`); `DisabledControlTips` handles disabled controls. Form-creating tests share `[Collection(WinFormsCollection.Name)]` to avoid competing STA message loops. Relevant classes include `ConfigurationBackupServiceTests`, `AdminPasswordServiceTests` and `TrayIntegrationTests`; shared gates are in `AGENTS.md`, installed UI qualification in `docs/tecnico/verifica.md`.

- Elevated GUI flows await `ElevatedConfigWriter.RunElevatedAsync`; only plain staging/arguments reach the worker. The form guards concurrent edits/close and restores controls in finally. Async save callers include notice revocation, guided setup and close-save. Runtime-created rows use `Ui.ScaleDynamic` once before attaching; later DPI changes belong to WinForms. Storage/Web support bounds use `Ui.Px`.

- OperationalStatusLabel retains selectable text; pass StatusLight.Working explicitly only for actual work. Tone.Warning alone maps to StatusLight.Paused (warning colour, ▲, «Avviso: leggere il motivo»), with no animation; pass StatusLight.Waiting explicitly for a real wait (UAC prompt). StatusDot reads SPI_GETCLIENTAREAANIMATION and high contrast. Capability commands (in the last tab, «Avanzate») use a full-width wrapping row (the label column otherwise clips Annulla); keep the Web probe label short with its cost explanation in the note. Tray frames/icons are cached and owned by the context; profile changes invalidate a pending health result, and health clients are disposed in finally.

- Data egress opens only from the explicit Privacy e dati command, with a per-profile destination/data/pseudonymization summary. Saving a cloud default without consent or revoking it is allowed; transport stays blocked. Acceptance/revocation is effective only after successful pair save; restore the previous authorization/history on failure or UAC denial. Connection checks in form/wizard/tray are cancellable with a total 10-second deadline; capability requests reject reentry and stale replies.
